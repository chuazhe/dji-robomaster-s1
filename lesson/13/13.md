## 1) Ask the user for a number. If the number is positive, check if it is even or odd and print the result.
<details>
  <summary>Show Hint</summary>
  Use one if inside another to check both conditions.
</details>

<br>
<details>
  <summary>Show Solution </summary>

  ```python
num = int(input("Enter a number: "))
if num > 0:
    if num % 2 == 0:
        print("Positive and Even")
    else:
        print("Positive and Odd")
else:
    print("Not positive")
  ```
</details>

## 2) Ask the user for their age. If the age is 18 or older, check if they are 65 or older and print "Senior", otherwise print "Adult". If the age is less than 18, print "Minor".

<details>
  <summary>Show Hint</summary>
  Use nested if to check for "Senior" inside the "Adult" check.
</details>
<br>
<details>
  <summary>Show Solution </summary>

  ```python
age = int(input("Enter your age: "))
if age >= 18:
    if age >= 65:
        print("Senior")
    else:
        print("Adult")
else:
    print("Minor")
  ```
</details>

## 3) Store a temperature value in temp. If temp is above 30, check if it is above 40 and print "Very Hot", otherwise print "Hot". If temp is 30 or below, print "Normal".
<details>
  <summary>Show Hint</summary>
   First check if temp is above 30, then check if it is above 40 inside that block.
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
temp = int(input("Enter temperature: "))
if temp > 30:
    if temp > 40:
        print("Very Hot")
    else:
        print("Hot")
else:
    print("Normal")
  ```
</details>

## 4) Store a score in score. If the score is 90 or above, check if it is 100 and print "Perfect!", otherwise print "Excellent". If the score is between 70 and 89, print "Good". If the score is below 70, print "Needs Improvement".

<details>
  <summary>Show Hint</summary>
   Use nested if for the "Perfect!" check inside the highest score block.
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
score = int(input("Enter score: "))
if score >= 90:
    if score == 100:
        print("Perfect!")
    else:
        print("Excellent")
elif score >= 70:
    print("Good")
else:
    print("Needs Improvement")
  ```
</details>
