## 2) Pause the program for a random number of seconds between 1 and 5.
<details>
  <summary>Show Hint</summary>
   Combine random.randint and time.sleep.
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
import time, random
time.sleep(random.randint(1, 5))
  ```
</details>
