# Trial
## 1) Ask the user for a number and print its square root.
<details>
  <summary>Show Hint</summary>
  Use math.sqrt() after converting input to float.
</details>

<br>
<details>
  <summary>Show Solution </summary>

  ```python
import math
n = float(input("Enter a number: "))
print(math.sqrt(n))
  ```
</details>

## 2) Generate a random integer between 1 and 100, then print its square root.

<details>
  <summary>Show Hint</summary>
  Use random.randint and math.sqrt.
</details>
<br>
<details>
  <summary>Show Solution </summary>

  ```python
import random, math
num = random.randint(1, 100)
print(math.sqrt(num))
  ```
</details>

## 3) Ask the user for a number, then print a random integer between 1 and that number (inclusive).
<details>
  <summary>Show Hint</summary>
   Use int(input()) and random.randint
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
import random
n = int(input("Enter a number: "))
print(random.randint(1, n))
  ```
</details>
