## 1) Keep asking the user for a number. If it is negative, print "Negative"; if zero, print "Zero"; else, print "Positive".
<details>
  <summary>Show Hint</summary>
  Use if-elif-else inside while True.
</details>

<br>
<details>
  <summary>Show Solution </summary>

  ```python
while True:
    n = int(input("Enter a number: "))
    if n < 0:
        print("Negative")
    elif n == 0:
        print("Zero")
    else:
        print("Positive")
  ```
</details>

## 2) Generate a random integer between 1 and 10 in each loop. If it is 1, print "One"; if 2, print "Two"; else, print "Other".

<details>
  <summary>Show Hint</summary>
  Use random.randint and if-elif-else.
</details>
<br>
<details>
  <summary>Show Solution </summary>

  ```python
import random
while True:
    num = random.randint(1, 10)
    if num == 1:
        print("One")
    elif num == 2:
        print("Two")
    else:
        print("Other")
  ```
</details>

## 3) Generate a random number between 1 and 15. If less than 5, print "Small"; if 5 to 10, print "Medium"; else, print "Large".
<details>
  <summary>Show Hint</summary>
   Use if-elif-else with comparison
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
import random
while True:
    num = random.randint(1, 15)
    if num < 5:
        print("Small")
    elif num <= 10:
        print("Medium")
    else:
        print("Large")
  ```
</details>

## 4) Write a function that asks the user for a number and prints "High" if it is greater than 100, "Low" otherwise.
<details>
  <summary>Show Hint</summary>
   Use if-else.
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
def high_or_low():
    n = input("Enter a number: ")

        print("High")
    else:
        print("Low")
high_or_low()
  ```
