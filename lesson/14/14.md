## 1) Ask the user for two numbers. If both numbers are positive, print "Both positive". Otherwise, print "At least one is not positive".
<details>
  <summary>Show Hint</summary>
  Use the and operator to check both conditions.
</details>

<br>
<details>
  <summary>Show Solution </summary>

  ```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
if a > 0 and b > 0:
    print("Both positive")
else:
    print("At least one is not positive")
  ```
</details>

## 2) Ask the user for their age. If the age is less than 18 or greater than 65, print "Not in working age". Otherwise, print "Working age".

<details>
  <summary>Show Hint</summary>
  Use the or operator to check for either condition.
</details>
<br>
<details>
  <summary>Show Solution </summary>

  ```python
age = int(input("Enter your age: "))
if age < 18 or age > 65:
    print("Not in working age")
else:
    print("Working age")
  ```
</details>

## 3) Ask the user for a number. If the number is not zero and is divisible by 3, print "Non-zero and divisible by 3". Otherwise, print "Does not meet criteria".
<details>
  <summary>Show Hint</summary>
   Use and and != together.
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
num = int(input("Enter a number: "))
if num != 0 and num % 3 == 0:
    print("Non-zero and divisible by 3")
else:
    print("Does not meet criteria")
  ```
</details>

## 4) Ask the user for two numbers. If either number is zero, print "At least one is zero". Otherwise, print "Neither is zero".

<details>
  <summary>Show Hint</summary>
   Use the or operator to check if either number is zero.
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
if a == 0 or b == 0:
    print("At least one is zero")
else:
    print("Neither is zero")
  ```
</details>
