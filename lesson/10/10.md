## 1) Ask the user for a number. If it is greater than 10, print "Big"; else, print "Small".
<details>
  <summary>Show Hint</summary>
  Use if-else and int(input()).
</details>

<br>
<details>
  <summary>Show Solution </summary>

  ```python
n = int(input("Enter a number: "))
if n > 10:
    print("Big")
else:
    print("Small")
  ```
</details>

## 2) Ask the user for a number. If it matches a random number between 1 and 5, print "Correct!"; else, print "Wrong!".

<details>
  <summary>Show Hint</summary>
  Compare user input and random number. 
</details>
<br>
<details>
  <summary>Show Solution </summary>

  ```python
  import random
user = int(input("Guess a number between 1 and 5: "))
rand = random.randint(1, 5)
if user == rand:
    print("Correct!")
else:
    print("Wrong!")
  ```
</details>

## 3) Ask the user for two numbers. If the first is larger, print "First is bigger"; else, print "Second is bigger or equal".
<details>
  <summary>Show Hint</summary>
   Use two input() calls and compare.
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
if a > b:
    print("First is bigger")
else:
    print("Second is bigger or equal")
  ```
</details>
