## 1) Keep asking the user for a number until they enter a number greater than 10, then print "Done".
<details>
  <summary>Show Hint</summary>
  Use a while loop
</details>

<br>
<details>
  <summary>Show Solution </summary>

  ```python
n = 0
while n <= 10:
    n = int(input("Enter a number greater than 10: "))
print("Done")
  ```
</details>

## 2) Ask the user for a password until they enter "python123". Print "Access granted" when correct.

<details>
  <summary>Show Hint</summary>
  Use a while loop and string comparison.
</details>
<br>
<details>
  <summary>Show Solution </summary>

  ```python
pwd = ""
while pwd != "python123":
    pwd = input("Enter password: ")
print("Access granted")
  ```
</details>

## 3) Keep generating random numbers between 1 and 10 until you get a 7. Print each number.
<details>
  <summary>Show Hint</summary>
   Use random.randint and a while loop.
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
import random
num = 0
while num != 7:
    num = random.randint(1, 10)
    print(num)
  ```
</details>
