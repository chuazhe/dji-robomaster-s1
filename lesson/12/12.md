## 1) Use a while loop to print numbers from 1 to 5. When done, print "Done!" using the else block.
<details>
  <summary>Show Hint</summary>
  Use a while else loop
</details>

<br>
<details>
  <summary>Show Solution </summary>

  ```python
i = 1
while i <= 5:
    print(i)
    i += 1
else:
    print("Done!")
  ```
</details>

## 2) use a while loop to find out the first mutiple of 4 from 1-10.
<details>
  <summary>Show Hint</summary>
  Use a while else loop
</details>

<br>
<details>
  <summary>Show Solution </summary>

  ```python
i = 1
while i <= 10:
    if i % 4 == 0:
        print("First multiple of 4:", i)
        break
    i += 1
else:
    print("No multiple of 4 found")
  ```
</details>

## 3) Ask the user to enter a password. Allow up to 5 attempts. If the correct password ("python123") is entered, print "Access granted". If not, print "Access denied" using the else block.
<details>
  <summary>Show Hint</summary>
  Use a while else loop
</details>

<br>
<details>
  <summary>Show Solution </summary>

  ```python
attempts = 5

while attempts > 0:
    pwd = input("Enter password: ")
    if pwd == "python123":
        print("Access granted")
        break
    attempts -= 1
else:
    print("Access denied")
  ```
</details>

## 4) Write a program that asks the user to guess a number between 1 and 10. The user has 3 attempts. If the user guesses correctly, print "You win!". If not, print "Sorry, you lost." using the else block.
<details>
  <summary>Show Hint</summary>
   Use random.randint and a while else loop.
</details>
<br>
<details>
  <summary>Show Solution </summary>
  
  ```python
import random

number = random.randint(1, 10)
attempts = 3

while attempts > 0:
    guess = int(input("Guess a number between 1 and 10: "))
    if guess == number:
        print("You win!")
        break
    attempts -= 1
else:
    print("Sorry, you lost.")
  ```
</details>
